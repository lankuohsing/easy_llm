# 强化学习（Reinforcement Learning，RL）

本目录先介绍通用强化学习基础，再介绍 PPO 和 GRPO，并用 LLM 生成任务解释它们如何用于策略训练。当前学习重点是 **RL 基础 → PPO → GRPO**；预训练和其他后训练专题暂时放在一边，完成这三部分后再决定 Agentic RL 的后续学习与落地内容。

## 本阶段学习顺序

| 顺序 | 教程 | 学习重点 | 学完应能做到 |
| --- | --- | --- | --- |
| 1 | [RL 基础理论](./01_rl基础理论.md) | 交互循环、MDP、状态与观测、奖励与回报、价值与优势、TD、策略梯度 | 能描述一个 RL 问题，手算回报和优势，区分奖励模型与 critic |
| 2 | [PPO 基础理论](./02_ppo基础理论.md) | Actor-Critic、GAE、旧策略概率比、裁剪目标、参考 KL 与训练流程 | 能解释 PPO 如何采样和更新，区分 clipping 与参考 KL，完成裁剪手算 |
| 3 | [GRPO 基础理论](./03_grpo基础理论.md) | 同 prompt 组采样、组相对优势、无 critic 更新与 PPO 对比 | 能手算组优势，解释零方差组及采样成本，说明与 PPO 的取舍 |

每章末尾都有自检问题。先沿上表顺序阅读，不需要预先读完 SFT、DPO 或本目录的选读专题。本阶段以基础理论和数值核对为主，尚未提供完整训练实验。

RL 基础章节中的 Python 数值核对只需要 Python 3 标准库和普通 CPU，不需要 GPU、外部输入数据或输出目录；运行后直接在终端显示结果。PPO 与 GRPO 中的代码为框架无关伪代码，不能直接当作训练脚本执行。
