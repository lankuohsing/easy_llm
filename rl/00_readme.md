# 强化学习（Reinforcement Learning，RL）

本目录先介绍通用强化学习基础，再介绍 PPO 和 GRPO，并用 LLM 生成任务解释它们如何用于策略训练。当前学习重点是 **RL 基础 → PPO → GRPO**；预训练和其他后训练专题暂时放在一边，完成这三部分后再决定 Agentic RL 的后续学习与落地内容。

## 本阶段学习顺序

| 顺序 | 教程 | 学习重点 | 学完应能做到 |
| --- | --- | --- | --- |
| 1 | [RL 基础理论](./01_rl基础理论.md) | MDP、回报与价值、MC/TD、轨迹概率 → 策略梯度 → reward-to-go → 基线 → 代理 loss | 能描述一个 RL 问题，手算回报和优势，解释不可微奖励如何训练策略 |
| 2 | [PPO 基础理论](./02_ppo基础理论.md) | Actor-Critic、TD → k 步回报 → GAE、重要性采样、概率比、裁剪、KL 与训练流程 | 能完整手算 GAE 和裁剪目标，正确处理终止、截断和固定 rollout |
| 3 | [GRPO 基础理论](./03_grpo基础理论.md) | 组采样与优势、序列 → token 更新、无 critic 目标、长度权重、KL 与 PPO 对比 | 能手算组优势，解释零方差组、组基线偏差及采样成本，说明与 PPO 的取舍 |

每章末尾都有自检问题。先沿上表顺序阅读，不需要预先读完 SFT、DPO 或本目录的选读专题。本阶段以基础理论和数值核对为主，尚未提供完整训练实验。

首次阅读先完成正文的例子、手算和训练流程；PPO 的 gamma-just 附录用于进一步核对“优势数值”和“策略梯度”的无偏条件，可以在正文之后阅读。

## 如何核对公式

基础章提供可复制的短例子；[跨章节数值核验脚本](./examples/verify_rl_math.py) 则用有限枚举、有限差分和独立表达式检查关键关系。在仓库根目录运行：

```bash
python3 rl/examples/verify_rl_math.py
```

依赖仅为 Python 3 标准库，普通 CPU 即可，无需 GPU 或大内存；不读取外部数据，也不创建输出文件。脚本会逐项打印核对结果，数值不一致时抛出异常并退出。

| 核对内容 | 核对方式 |
| --- | --- |
| 策略梯度、reward-to-go 与动作无关基线 | 穷举随机转移的两步环境，与真实目标的有限差分比较 |
| 局部概率比代理目标 | 在新旧策略相同时比较一阶梯度 |
| GAE 与 lambda-return | 逆序递推与有限 k 步加权混合交叉比较，检查 lambda 两端及终止／截断 |
| 重要性采样 | 精确计算期望与稀有大权重导致的方差 |
| PPO 裁剪 | 检查正负优势的四种边界情况及其有限差分梯度 |
| GRPO 组基线与 KL | 枚举 iid 奖励组，核对组均值缩放、零方差组、组优势与 k3 梯度 |

这些小例子帮助发现公式和边界处理错误，一般结论仍依赖正文中的假设与推导。PPO 与 GRPO 中的训练代码为框架无关伪代码，不能直接当作训练脚本执行。

## 阅读时要分清的条件

教程借鉴已有 PPO 笔记的推导结构，并对照 GAE、PPO、DeepSeekMath 和 DeepSeek-R1 原文核对关键结论。各章末尾注明参考来源；公式统一使用从 1 开始的时间下标，以及相容的策略、价值和概率比记号。

- Monte Carlo / TD 描述回报估计方式；online / offline 和 on-policy / off-policy 描述数据收集与使用方式。
- 折扣因子属于目标定义，改变它可能改变动作排序；不能只把它看成数值缩放。
- 完整回报减去固定、动作无关的错误基线，仍可保持梯度期望；错误 bootstrap 与使用本样本奖励构造基线需要另行分析。
- PPO clipping 提供保守的更新激励，不保证实际概率比或 KL 满足硬边界；旧策略与参考策略承担不同角色。
- GRPO 的组标准化和回答长度权重会改变更新信号；KL 数值估计正确也不自动说明固定样本反传得到相同 KL 的梯度。

这些条件会直接影响后续复现：先明确目标、采样分布、聚合方式和计算图，再把公式映射到训练框架。
