# LLM 强化学习中的熵坍塌与熵爆炸：机制、干预与诊断

## 摘要

在 GRPO、PPO 及其变体训练大语言模型时，策略熵经常出现快速下降，并伴随采样回答趋同、探索能力减弱和性能提升停滞。这通常称为熵坍塌（entropy collapse）。另一方面，过强的熵激励、不合理的损失聚合或训练失稳，也可能造成熵快速升高及生成质量退化，部分论文将其称为熵爆炸（entropy explosion）。

本文从 next-token 分布的 Shannon 熵出发，解释两种现象的数学含义、GRPO 中的形成机制和工程诊断方法，并比较 Clip-Higher、Clip-Cov、KL-Cov、熵正则、参考模型 KL 和目标熵控制等干预手段。核心结论是：熵增减本身并不决定训练好坏；训练需要保留能够发现并强化优质解法的探索，同时维持稳定的语言生成能力。固定词表下的逐 token 熵具有有限上界，因此“熵爆炸”通常描述异常快速增长，而不是数学意义上的无穷发散。

本文为文献综述与机制分析，不包含新增训练实验。主要证据来自 DAPO、熵机制研究和 AEPO，见文献 [1]–[3]。资料查阅日期：2026 年 10 月 15 日。

**关键词：** LLM；GRPO；RLVR；策略熵；探索；熵坍塌；熵爆炸；信用分配。

## 1. 研究范围与符号约定

本文主要讨论使用序列级奖励的 LLM 强化学习，尤其是数学、代码等带可验证奖励的任务，即 RLVR（Reinforcement Learning with Verifiable Rewards）。部分机制也适用于 PPO 和使用奖励模型的 RLHF，但具体效果取决于模型初始化、奖励、数据、采样和训练实现。

建议先阅读 [GRPO 基础理论](./03_grpo基础理论.md)；需要了解价值模型和 PPO 时，可参考 [PPO 基础理论](./02_ppo基础理论.md)。本文沿用这两篇文档的主要符号。

| 符号 | 含义 |
| --- | --- |
| $\mathcal D$ | 训练提示词分布 |
| $\mathcal V$ | tokenizer 词表 |
| $x$ | 提示词 |
| $y_i$ | 同一提示词下第 $i$ 条回答 |
| $G$ | 每个提示词的回答数量 |
| $T_i$ | 回答 $y_i$ 的有效 token 数量 |
| $s_{i,t}$ | 当前上下文，即提示词和回答前缀 |
| $a_{i,t}$ | 实际生成的 token |
| $\pi_\theta$ | 当前策略模型 |
| $\pi_{\mathrm{old}}$ | 生成当前 rollout 的旧策略 |
| $\pi_{\mathrm{ref}}$ | 通常在整个训练阶段冻结的参考策略 |

$$

$$

## 2. 熵的定义、测量与现象边界

### 2.1 next-token 熵与平均 token 熵

对固定上下文 $s$ ，Shannon 熵定义为：

$$
H_\theta(s)=-\sum_{a\in\mathcal V}\pi_\theta(a\mid s)\log\pi_\theta(a\mid s)
$$

本文使用自然对数，单位为 nat。概率接近集中在一个 token 上时，熵接近 0；分布更均匀时，熵更高。概率为 0 的项按连续延拓取贡献为 0。

以同一提示词下的一组回答为例，对全部有效回答 token 等权平均，可写成：

$$
\bar H=\frac{\sum_{i=1}^{G}\sum_{t=1}^{T_i}H_\theta(s_{i,t})}{\sum_{i=1}^{G}T_i}
$$

另一种实现先对每条回答取平均，再对回答取平均。两种口径会赋予不同长度的回答不同权重，训练日志必须说明采用哪一种。

如果上下文来自当前策略的 rollout，平均熵还会随访问到的上下文变化。因此，曲线变化可能同时来自模型分布变化、回答长度变化和上下文组成变化。跨 checkpoint 比较时，固定一组 prompt 和 prefix 更容易分离模型自身的变化。

### 2.2 策略熵、采样熵与采样负对数概率

采样温度、top-p 和 top-k 会改变实际采样分布。用 $q(a\mid s)$ 表示最终采样器的条件分布，它不一定等于未变换的当前模型分布。

仅应用正温度 $\kappa$ 时，变换后的分布为：

$$
q_\kappa(a\mid s)=\frac{\exp\left(z_\theta(s,a)/\kappa\right)}{\sum_{b\in\mathcal V}\exp\left(z_\theta(s,b)/\kappa\right)}
$$

在此基础上再做 top-p 或 top-k 截断，才得到最终采样分布。采样参数的变化与模型参数的变化应分别记录。

在固定上下文下，对采样 token 的负对数概率取期望，有：

$$
\mathbb E_{a\sim q(\cdot\mid s)}\left[-\log\pi_\theta(a\mid s)\right]=H(q(\cdot\mid s))+D_{\mathrm{KL}}\left(q(\cdot\mid s)\|\pi_\theta(\cdot\mid s)\right)
$$

当采样分布等于当前模型分布时，样本负 log probability 的均值是当前 Shannon 熵的无偏估计。一般情况下，采样分布与被测分布不同时，应将上式左侧解释为交叉熵，不能直接等同于当前策略熵。例如，用旧 rollout 的 token 计算当前模型的平均负 log probability，就存在这种区别。

排查问题时应分别记录：

- 温度为 1、未做 top-p/top-k 截断时，模型完整词表分布的熵；
- 温度和截断变换之后，实际采样分布的熵；
- rollout token 的负 log probability，以及计算它所用的模型版本。

这里的“完整词表”指被测模型概率分布的完整候选集合；如果系统使用合法动作 mask，应记录 mask 并在比较时保持一致。

### 2.3 熵坍塌、正常收敛与熵爆炸

| 现象 | 常见表现 | 判断依据 |
| --- | --- | --- |
| 正常概率集中 | 模型越来越偏向正确或高质量输出，熵逐渐下降 | 验证表现持续改善，任务所需的多样性仍然足够 |
| 熵坍塌 | 熵过早或过快下降，回答趋同，替代路径难以采到 | 探索减弱，并出现性能停滞或脆弱的模式锁定 |
| 正常熵增长 | 原本低概率的优质候选获得更多概率 | 输出质量和任务表现改善，采样仍然有效 |
| 病理性熵增长 | 熵快速升高，生成散乱，正确率或正常结束率下降 | 随机性增长没有转化为有效学习 |

固定词表下，逐 token 熵满足：

$$
0\le H_\theta(s)\le\log|\mathcal V|
$$

因此，真实逐 token 熵不会趋向无穷大。若日志出现无界增长，应检查它是否实际记录了负 log probability、序列总和或包含数值错误。回答变长可能推高累计 token 熵，但这与平均 token 熵是不同指标。

此外，局部 token 熵不等同于推理路径的语义多样性。模型可以用多种措辞表达同一种解法，也可以在少数关键分支上产生不同解法。需要同时检查解题方法、答案类型和采样成功率，不能仅用平均熵判断探索质量。

## 3. 熵变化的数学机制

### 3.1 固定上下文下的一阶变化

语言模型在固定上下文下通过 softmax 得到概率：

$$
\pi_\theta(a\mid s)=\frac{\exp z_\theta(s,a)}{\sum_{b\in\mathcal V}\exp z_\theta(s,b)}
$$

对某个候选 token 的 logit 求导，有：

$$
\frac{\partial H_\theta(s)}{\partial z_\theta(s,a)}=-\pi_\theta(a\mid s)\left(\log\pi_\theta(a\mid s)+H_\theta(s)\right)
$$

设一次更新使 logits 发生变化，记为：

$$
\Delta z(s,a)=z_{\theta_{\mathrm{new}}}(s,a)-z_\theta(s,a)
$$

固定同一个上下文、在更新足够小的一阶近似下，熵变化为：

$$
\Delta H(s)\approx-\mathrm{Cov}_{a\sim\pi_\theta(\cdot\mid s)}\left(\log\pi_\theta(a\mid s),\Delta z(s,a)\right)
$$

协方差在更新前的动作分布下计算。这个式子说明：

- 如果原本概率较高的候选也获得较大的 logit 增长，协方差倾向于为正，熵倾向于下降；
- 如果更新主要提升原本稀有的候选，熵可能上升；
- 优势为正不意味着熵必然下降，关键在于整个分布中的概率如何重新分配。

文献 [2] 分析了这一机制，并在其训练实验中观察到多数更新的相关协方差保持为正，对应持续的熵消耗。

这里有两个适用边界。第一，上式描述固定上下文上的局部变化，不能直接解释上下文分布也发生变化的全部日志波动。第二，优势通过模型参数、优化器、clipping 等环节影响 logits；不同参数化下的 logit 更新关系不同。Transformer 共享参数还会耦合多个位置，因此不能把“奖励与概率相关”直接当作所有 GRPO 实现都满足的精确更新定律。

### 3.2 熵先升后降，也可能一直在学习

考虑一个教学用的二选一任务：一个动作正确，另一个错误，正确动作的概率为 $p$ 。其熵为：

$$
H(p)=-p\log p-(1-p)\log(1-p)
$$

| 正确动作概率 | 熵，单位 nat | 含义 |
| --- | --- | --- |
| 0.01 | 约 0.056 | 策略高度偏向错误动作 |
| 0.50 | 约 0.693 | 两个动作概率相同 |
| 0.99 | 约 0.056 | 策略高度偏向正确动作 |

如果训练使正确概率按表中顺序提高，熵先升后降，期望正确率却持续增加。这个例子说明，正常的策略纠偏可以经历熵增长；低熵本身也不说明策略正确。该例是分布性质演示，不是某个语言模型的实验结果。

## 4. GRPO 中熵坍塌的形成机制

### 4.1 奖励目标允许确定性最优策略

忽略熵和 KL 正则时，抽象任务目标为：

$$
\mathcal J_{\mathrm{reward}}(\theta)=\mathbb E_{x\sim\mathcal D,\,y\sim\pi_\theta(\cdot\mid x)}\left[r(x,y)\right]
$$

这个目标不要求保留多种解法。在理想化的固定奖励、策略表达能力足够的情形下，对一个提示词把概率集中到最高奖励的回答，也能最大化期望奖励。

因此，熵下降可以是利用已有好策略的正常结果。坍塌强调的是集中发生得过早：模型锁定的是当前有限样本中表现较好的路径，未必是具有最佳泛化表现的路径。

### 4.2 有限采样与概率强化形成反馈

在有限 group size 下，高概率路径更容易被采到；成功样本又推动其相关 token 概率上升。低概率的替代解法得到奖励的机会更少，可能逐渐退出实际采样范围。

这一反馈在稀疏奖励中更明显。数学答案校验和代码测试通常在完整回答生成后才给出奖励，模型需要先采到足够完整的成功路径，才能得到正向学习信号。增加 group size 能扩大搜索机会，但会增加 rollout 和验证成本，也不能保证出现新的有效路径。

序列级优势还带来信用分配问题。当一条回答的有效 token 共享一个优势时，真正起作用的推理步骤、固定表达和偶然伴随成功的内容可能一起得到强化。这增加了有限样本中的偶然模式被固定下来的风险。

### 4.3 对称上裁剪可能较早限制稀有优质候选

GRPO 使用新旧策略概率比：

$$
\rho_{i,t}(\theta)=\frac{\pi_\theta(a_{i,t}\mid s_{i,t})}{\pi_{\mathrm{old}}(a_{i,t}\mid s_{i,t})}
$$

对正优势 token，对称 clipped objective 在概率比超过上阈值后，不再提供继续提高该样本概率的额外收益。以 $\varepsilon=0.2$ 为例：

| 旧策略概率 | 正优势分支的名义上裁剪位置 | 实际含义 |
| --- | --- | --- |
| 0.01 | 0.012 | 很小的绝对概率增长就触及裁剪 |
| 0.90 | 1.08 | 该位置超过合法概率范围，概率接近 1 时仍未触及这一阈值 |

文献 [1] 据此提出 Clip-Higher，增加正优势分支的上裁剪空间，以帮助低概率优质候选获得更充分的强化。

表中的数值是代理目标的裁剪位置，不是模型概率的硬上限。其他样本、共享参数和正则项仍会改变该 token 的概率；更换旧策略后，新的更新也可以继续推动概率集中。

### 4.4 组内标准化可能放大细小奖励噪声

沿用 GRPO 章节中的定义：

$$
\bar r=\frac{1}{G}\sum_{j=1}^{G}r_j,\qquad \sigma_r=\sqrt{\frac{1}{G}\sum_{j=1}^{G}(r_j-\bar r)^2}
$$

$$
\hat A_i=\frac{r_i-\bar r}{\sigma_r+\epsilon_{\mathrm{std}}}
$$

如果两条回答只因评分噪声分别得到 0.5001 和 0.4999，在数值稳定常数相对较小时，标准化后仍可能得到接近正负 1 的优势。因此，细小且不可靠的评分差异也可能产生明显更新。

但标准化优势不会仅因标准差小而无界爆炸。采用上述同组总体标准差、组大小至少为 2、数值稳定常数为正时，有：

$$
|\hat A_i|\le\sqrt{G-1}
$$

真正需要关注的是：标准化是否把评分噪声当成有效差异，以及不同 prompt 是否因标准化而获得不合适的相对权重。这个界也不限制概率比、模型 Jacobian 或优化器造成的梯度异常。

### 4.5 组内优势归零与熵坍塌可能互相影响

同组奖励全部相同时，各回答的中心化奖励和优势都为 0。对二元正确性奖励而言，全对组和全错组都属于这种情况。

回答趋同可能增加同奖励组；有效组减少又会缩小任务学习信号、增加训练停滞的风险。但组内优势归零与熵坍塌并不是同一个事件：全错组也可能包含多种错误解法，全对组也可能包含多种正确解法。

另外，优势为 0 只使该组的任务策略项失去梯度。熵正则、参考模型 KL，以及其他 prompt 的梯度仍可能更新模型。

### 4.6 更新尺度与长期约束影响坍塌速度

较大的学习率、较多的 rollout 复用、较强的局部更新，都可能使分布更快集中。随着当前策略偏离采样策略，旧数据上的估计也可能变得不可靠。

参考模型 KL 可以抑制长期行为漂移，但不是熵下限。参考策略本身较确定时，更强的 KL 也可能把当前策略拉向较低熵的分布。无参考 KL 的训练不一定坍塌，有参考 KL 的训练也不一定能保持足够探索。

## 5. 熵坍塌的干预方法与取舍

### 5.1 控制更新尺度与 rollout 新鲜度

若熵在短时间内明显下降，同时新旧策略 KL、概率比尾部或 clip fraction 发生较大变化，应先检查学习率、每批 rollout 的更新次数和采样策略同步。

常见处理是降低学习率、减少同一批数据的复用，并缩短采样策略与训练策略的版本差距。目的在于降低单轮漂移，让后续采样能够及时反映当前策略。更新过小也会降低学习效率，需要结合验证表现和训练成本选择。

### 5.2 Clip-Higher

DAPO 将对称裁剪改为分别设置上下阈值：

$$
\mathrm{clip}\left(\rho_{i,t},1-\varepsilon_{\mathrm{low}},1+\varepsilon_{\mathrm{high}}\right)
$$

提高上阈值，为低概率正优势 token 提供更多增长空间；保留下阈值，避免同时过度放宽负优势动作的概率下降。文献 [1] 的实验采用下裁剪参数 0.2、上裁剪参数 0.28，这些是其模型和训练配置中的取值，不是通用最优参数。

Clip-Higher 针对上裁剪限制探索候选的问题。它不负责消除奖励噪声，也不保证真实 KL 始终受控；放宽上阈值后仍需检查策略漂移。

### 5.3 Clip-Cov 与 KL-Cov

文献 [2] 观察到，少量具有较高协方差代理值的 token 可能主导快速熵消耗，并提出两种方法：

- **Clip-Cov：** 在指定的协方差代理值范围内随机选取少量 token，将其策略损失 detach，阻断对应的直接梯度；
- **KL-Cov：** 选取代理值较大的少量 token，以 rollout 旧策略为参照施加局部策略差异惩罚。

这里必须区分理论量与实现中的代理量。固定上下文下的理论协方差涉及完整候选分布；论文的实用选择指标则由 rollout 中已采样 token 的 log probability 与优势构造，不能视为每个上下文真实熵变化的精确测量。

KL-Cov 的参照对象是生成 rollout 的策略，与长期冻结参考模型的 KL 不同。复现时还需核对论文公式、伪代码和训练框架实际使用的惩罚形式。

这两种方法在文献 [2] 的数学推理实验中缓解了坍塌并改善表现，其优势不应直接推广到所有模型、奖励和任务。

### 5.4 熵正则与参考模型 KL

为说明不同项的作用，设 $\mathcal J_{\mathrm{policy}}$ 只包含策略代理目标，不包含已有的参考 KL 项；对选定上下文计算平均参考 KL，记为 $K_{\mathrm{ref}}$ 。一个示意性的最大化目标为：

$$
\mathcal J_{\mathrm{reg}}(\theta)=\mathcal J_{\mathrm{policy}}(\theta)+\alpha\bar H-\beta K_{\mathrm{ref}}
$$

熵项直接鼓励分布保持随机性，参考 KL 则提供行为锚点。训练代码最小化 loss 时，熵项的符号应为负，参考 KL 惩罚的符号应为正。若原有目标已经包含 KL，不应再不加区分地重复添加。

两种正则都需要核对权重和聚合口径。文献 [2] 在其实验中发现，熵系数过小作用有限，过大可造成熵爆炸；部分设置虽然稳定了熵，却没有改善表现。参考 KL 也可能维持熵，同时限制任务学习。

因此，选择正则强度时应同时看验证表现、有效组比例、生成质量和各项梯度贡献。仅比较 loss 数值或仅追求一条平稳的熵曲线，不能确定正则是否合适。

### 5.5 目标熵控制与采样温度

目标熵控制根据当前熵相对目标的偏差调整干预强度，有助于避免固定系数在整个训练阶段中持续过强或过弱。目标应通过验证表现和有效探索确定，不能直接设为词表熵上界。

文献 [3] 的 AEPO 将温度调整后的采样分布与 REINFORCE 辅助梯度结合，在其 RLVR 实验中使熵维持在指定水平附近。它还观察到，表现随熵增大先改善、随后下降。这是特定实验中的证据，不意味着所有任务存在相同的最佳熵区间。

单独调高采样温度通常会增加采样随机性，但不会修改模型参数。这些样本进入训练并产生有效梯度后，模型策略才可能随之改变。已经非常集中的策略，也可能需要很高温度才能产生明显变化，此时应同时检查样本质量。

### 5.6 维持有效奖励组与改善奖励质量

DAPO 的动态采样对没有组内奖励差异的 prompt 进行过滤并补采，维持有效任务信号。题目难度安排、奖励区分能力和验证器可靠性也会影响有效组比例。

这些措施主要改善学习信号和训练稳定性，并不直接给熵设置下限。过滤会改变实际训练 prompt 的分布，还应记录不同难度的覆盖情况、补采成本和验证表现。

## 6. 熵爆炸的原因与处理

### 6.1 熵激励逐渐压过任务学习

如果熵正则权重过大，优化器可能主要推动分布变平。当有效奖励组减少、任务梯度减弱时，即使熵系数保持不变，其相对影响也可能增大。

文献 [2] 第 4.1 节和文献 [3] 均报告过过强熵激励造成异常熵增长的实验。应降低熵权重，或使用随训练状态调整的干预，同时核查有效组和正则梯度贡献。

若实现使用累计 token 熵作为激励，其值还会受到回答长度影响。改变长度可能改变正则总量，因此应明确采用求和、回答平均还是有效 token 平均。

### 6.2 长回答的不良模式被惩罚得过轻

为说明长度权重，定义不含参考 KL 的逐 token 策略代理项：

$$
\ell_{i,t}=\min\left(\rho_{i,t}\hat A_{i,t},\,\mathrm{clip}(\rho_{i,t},1-\varepsilon,1+\varepsilon)\hat A_{i,t}\right)
$$

对同一组回答，先按回答平均与按有效 token 平均分别为：

$$
\mathcal J_{\mathrm{response}}=\frac{1}{G}\sum_{i=1}^{G}\frac{1}{T_i}\sum_{t=1}^{T_i}\ell_{i,t}
$$

$$
\mathcal J_{\mathrm{token}}=\frac{\sum_{i=1}^{G}\sum_{t=1}^{T_i}\ell_{i,t}}{\sum_{i=1}^{G}T_i}
$$

前者使每条回答的总权重相同，但长回答中每个 token 的权重更小。文献 [1] 观察到，这可能削弱对长乱码等不良模式的惩罚，伴随熵和回答长度异常增长。

可采用更合适的 token-level 聚合，并检查超长回答的奖励、截断方式和结束行为。修改聚合同时会改变长短回答的相对权重，需要一起评估，而不能把 token 平均视为任何任务上的统一最佳选择。

重复生成也可能由低熵的循环模式造成。因此，看到重复文本时仍需测量分布，不能仅凭输出症状认定熵爆炸。

### 6.3 策略更新或实现异常

过大的更新、陈旧 rollout、错误的概率记录、token 对齐和正则符号，都可能导致分布异常变化。此类失稳既可能表现为熵升高，也可能表现为熵下降。

对于突然跳升的曲线，应优先核对：

- rollout 对应的模型版本，以及保存的行为 log probability；
- 采样温度、top-p/top-k 变换与训练概率比之间的关系；
- prompt、padding、结束 token 和截断 token 的 mask；
- 奖励、优势、KL 和熵项的符号、有限性及聚合权重；
- 新旧策略 KL、概率比尾部、梯度范数和数值精度。

不同框架对采样变换及重要性修正的处理不同，不能只凭“温度不是 1”就判定实现错误。应依据实际目标和采样分布核对估计方式。确认失稳后，可从异常前的 checkpoint 恢复，并调整更新尺度或修正实现。

### 6.4 奖励偏好无效随机性或过长输出

如果多样性、长度或格式分数与正确性缺少约束，模型可能通过无效变化或冗长内容得分。此时需要检查奖励分项与真实任务表现的关系，修正验证器、奖励聚合或门控。

过程奖励可以提供更细的信用分配，但也引入新的评分误差。应先核查奖励可靠性，再判断它是否有助于探索。

## 7. 工程诊断流程

### 7.1 建立可比较的观测口径

首先保留两套观测：一套来自训练 rollout，用于观察实际采样行为；另一套来自固定 prompt 和 prefix，用于比较模型分布。

固定观测应保持 tokenizer、候选集合、温度、mask 和 token 权重一致。建议同时记录均值、分位数，以及不同题目难度、正确与错误回答上的统计，避免一个平均数掩盖局部退化。

| 观测维度 | 建议指标 | 可以帮助判断的问题 |
| --- | --- | --- |
| 分布随机性 | 固定 prefix 的完整分布熵、实际采样熵、最大 token 概率 | 模型是否变得过度集中或分散 |
| 任务表现 | 训练奖励、独立验证正确率、固定采样预算下的成功率 | 随机性变化是否带来有效学习 |
| 学习信号 | 有效奖励组比例、奖励差异、优势分布 | 任务梯度是否逐渐消失或受噪声主导 |
| 生成行为 | 长度分布、正常结束率、截断率、乱码与重复比例 | 语言生成和终止行为是否退化 |
| 策略漂移 | 新旧策略 KL、参考 KL、概率比尾部、clip fraction | 更新是否过强，rollout 是否过旧 |
| 优化状态 | 梯度范数、各目标项的梯度贡献、非有限值 | 正则是否主导或存在数值失稳 |
| 语义探索 | 解题方法分布、去重后的有效路径、成功路径多样性 | token 随机性是否转化为有用的新解法 |

KL 和 clip fraction 也必须记录计算口径。采样估计、完整分布计算和不同裁剪分支统计，不能直接混作同一个数值比较。

### 7.2 按证据选择处理顺序

1. **先确认测量正确。** 排除温度、长度、上下文和模型版本变化造成的表观熵波动，区分 Shannon 熵与采样负 log probability。
2. **检查实现和数值。** 若曲线突然跳变，同时概率比、梯度或 KL 异常，先修复概率、mask、正则符号或更新问题。
3. **判断任务信号是否有效。** 检查同奖励组、奖励噪声和验证器，再决定是否调整难度、动态采样或奖励。
4. **定位干预对象。** 上裁剪限制稀有优质候选时考虑 Clip-Higher；少量更新主导熵消耗时考虑协方差相关方法；正则主导时调整熵或 KL 权重。
5. **用验证结果决定是否保留修改。** 保持评测采样预算一致，同时比较表现、生成质量和计算成本。

## 8. 干预方法的验证与结论边界

### 8.1 建议的对照评估

评估一种干预时，应固定模型初始化、数据与奖励版本、rollout 采样配置和评测配置，尽量一次只改变一个关键因素。涉及多个组件时，再进行组合与消融比较。

仅匹配训练步数不足以比较效率。例如，动态采样会增加补采，长回答会增加生成和验证成本。应同时报告训练 token 数、rollout 数量、验证成本和实际耗时；计算条件允许时，使用多个随机种子检查稳定性。

不存在适用于所有模型与任务的统一熵阈值。可接受范围应由任务表现、正常生成能力和继续探索的收益共同确定。

### 8.2 对论文证据的解释

| 来源 | 与本文相关的证据 | 适用边界 |
| --- | --- | --- |
| DAPO [1] | 初始训练中的坍塌；Clip-Higher；损失长度权重相关的异常熵增长；动态采样 | 多个训练组件共同影响结果，不能把全部提升归因于熵 |
| 熵机制研究 [2] | 固定状态的一阶熵变化分析；熵与表现的经验关系；熵正则过强时的爆炸；Clip-Cov 与 KL-Cov | 经验拟合和干预收益依赖实验配置，不是普遍性能定律 |
| AEPO [3] | 温度调整分布与辅助策略梯度的熵控制；熵与表现先升后降的实验关系 | 目标熵范围和最佳水平需在具体任务中验证 |

这些研究支持“管理探索对持续学习很重要”，但不支持“熵越高越好”或“只要稳定熵就能提升能力”。熵下降可能伴随有效收敛，熵上升可能伴随正常纠偏；真正需要干预的是过早丧失有效探索、无效随机性增长或训练实现失稳。
